# Compléments confirmés pour les institutions

Lot confirmé par l’utilisateur et appliqué à la base : 20 fiches complétées, 3 institutions ajoutées, 252 types déduits des noms existants.

Les noms approuvés sont conservés. Le type est déduit uniquement lorsqu’il est explicite dans le nom (Centre de Santé, Hôpital, HCR, etc.). Les bureaux ou établissements ambigus restent à renseigner.
